说明

· 机顶盒本身多久拉一次订阅由 TVBox 客户端决定，一般重启或手动「刷新配置」时更新。
· 通过网关修改的配置（屏蔽词、源开关、排序、LOGO）与 LunaTV 完全独立，不会影响网页端。
· 订阅配置由网关常驻内存缓存，机顶盒打开时直接命中，不再等 LunaTV 拉源（原 5-10 秒 → 毫秒级）。
· 源分类/首页列表也做了短缓存，翻页与搜索始终实时。
· 搜索走「搜索全部源 + 额外聚合源数量」配合：主源合并其它启用源的结果，数量限制真正有结果的额外源个数。
· 概览「实时在线设备」按最后数据流时间判定在线，日/月接入统计落盘到 cache/devices.json，重启不丢；NAS 上的 LunaTV 服务（192.168.3.100）属服务流量，不计入设备。
· 概览的四项统计（分类拦截 / 标题拦截 / TMDB 命中 / TMDB 未收录）累计与本月数据写入 NAS，重启不清零；月度明细只保留当月，跨月自动覆盖。
· 修改 guard.py 代码后需执行 docker compose up -d --force-recreate 才生效。
